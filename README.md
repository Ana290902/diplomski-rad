# Primjena statističkih metoda u procesu izgradnje skladišta podataka

Ovaj repozitorij sadrži programske kodove korištene u praktičnom dijelu diplomskog rada izrađenog na Prirodoslovno-matematičkom fakultetu Sveučilišta u Zagrebu.

## Opis projekta

Praktični dio rada obuhvaća obradu podataka i izgradnju skladišta podataka.

## Korišteni podaci

U radu je korišten javno dostupan skup podataka Brazilian E-Commerce Public Dataset by Olist.

Izvor: Olist, and André Sionek. (2018). Brazilian E-Commerce Public Dataset by Olist [Dataset]. Kaggle. https://doi.org/10.34740/KAGGLE/DSV/195341

## Sadržaj repozitorija

- `python/` – Python skripte i Jupyter bilježnice
- `sql/` – SQL skripte za izgradnju skladišta podataka

## Korištene tehnologije

- Python
- SQL
- Jupyter Notebook
